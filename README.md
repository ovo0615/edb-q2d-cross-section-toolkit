# EDB → Q2D Cross-Section Toolkit

Place a cut line on an Ansys EDB layout; get the **real** cross-section rebuilt and solved
in Ansys Q2D Extractor.

在 Ansys EDB 的 Layout 上指定一條切線，把該處**真實**的層截面重建到
Ansys Q2D Extractor 並求解特徵阻抗。

> **Front-end showcase.** The EDB reader, cross-section scanner and Q2D solver are a private
> back end and are not published here — the interface alone cannot import a board.
> 本儲存庫只公開前端；EDB 讀取、截面掃描與 Q2D 求解為私有後端，只有前端無法匯入電路板。
